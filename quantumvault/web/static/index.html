VERIFIED CRYPTOGRAPHIC ASSURANCES FIPS 203 / 204
● Ephemeral ML-KEM-768 Handshake:

Bob generates a fresh 1184-byte ephemeral public key and signs the offer. Alice encapsulates a 1088-byte ciphertext and derives HKDF-SHA256 directional session keys.

● Post-Compromise Forward Secrecy:

Mutable ephemeral private key buffers are overwritten in RAM upon decapsulation. Theft of long-term identity signing keys cannot decrypt captured historical transcripts (noting CPython immutable bytes caveats).

● Recipient & Context Binding:

AES-256-GCM ciphertexts bind session ID, sequence number, sender/recipient IDs, devices, and timestamp in AAD. Modified ciphertext or altered recipient metadata fails AEAD tag check.

● Session Resumption Policy:

Intentionally NOT SUPPORTED (`SecurityPolicyError`) to eliminate persistent session ticket and PSK compromise attack surfaces.
